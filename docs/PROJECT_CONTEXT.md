# FitOrder 프로젝트 맥락

## 목적
카카오톡 이미지·메시지·Excel·PDF 등 제각각인 발주 입력을 표준 주문 데이터로 만든 뒤
장부 / 작업지시서 / 경영박사 ERP(EDI)까지 자동화한다. 하루 약 400건 규모를 상정한다.

## 핵심 UX
- 시작 화면: 블라인드 / 롤·콤비 / 홀딩도어
- 블라인드: 왼쪽 입력 유지 + 오른쪽 사전점검 장부
- 사전점검에서 사용자가 수정한 값이 최우선
- 상태: 오류(빨강), 확인(노랑), 중복/검토(보라)
- 상태 클릭 → 원본 + 사유
- Alt+1 병합 / Alt+2 해제 / Ctrl+Z / Delete / F2
- 자동 병합 금지
- 선택행과 하단 부가정보(주소·부속·전달사항·손잡이길이) 연동

## 데이터 흐름
입력
→ 업체 판별
→ 이미지 AI 또는 Excel parser
→ 표준 주문 schema
→ 규칙 검증
→ 사용자 사전점검/수정
→ 장부
→ 작업지시서
→ 경영박사 EDI

## 표준 주문
Order:
- 거래처
- 주문번호
- 고객명
- 전체기재사항
- 배송 {방식, 선불착불, 주소, 수령인, 연락처, 전달사항, 발신}
- items[]
Item:
- 품목코드 / 종류 / 타입
- 가로 / 세로 / 창개수
- 좌개수 / 우개수
- 손잡이방향 / 손잡이길이
- 연창 / 특이 / 기재사항 / 설치장소
