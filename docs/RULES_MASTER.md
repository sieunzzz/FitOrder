# FitOrder 확정 규칙 MASTER — 2026-09-13

## 공통
- 장부 상단 날짜 = 오늘.
- 출고일은 별도 달력 선택. 배달/택배/화물/내사/없음 지원.
- 가로 숫자의 불필요한 `.0` 제거.
- FP/P는 셀 전체가 아니라 **숫자+P/FP 코드 부분만 파란색**.
- 일반 블라인드:
  - 원코드 가로 36cm 미만 → 가로 숫자 파란색.
  - 투코드·셔터 가로 30cm 미만 → 가로 숫자 파란색.
  - 세로 370cm 초과 → 세로 숫자 파란색.
- 연창: 블라인드는 자동 추론 가능. 롤/콤비는 자동 추론하지 않는다.
- 사용자가 사전점검에서 수정한 값이 자동판독보다 우선.
- 자동 병합 금지. 사용자가 직접 병합한 경우에만 유지.
- 기재사항 중복 전산 입력 금지. 1→2 순서.
- 장부/작업지시서/EDI에 동일 수정사항이 반영되어야 한다.
- ERP 주소에서 번지 뒤 불필요한 쉼표 제거.

## 기재사항
- DI·휴안: 기재사항1만 사용.
- 그 외 일반 업체: 여러 창일 때 기재1=공통 규칙, 기재2=개인창 규칙.
- 기재사항1에는 주문번호를 반드시 포함.
- JO: 3창 이상일 때만 기재사항2 사용.
- DD처럼 기재사항1이 여러 번 반복되지 않게 한 주문에서 공통값 1회 중심으로 출력.

## 배송
- 택배 주소: 시부터 간소화해서 기록. 예: `서울특별시` → `서울시`.
- 화물: `지점 - 받는사람 / 전화`. 보노 계열은 전화번호 앞 `/` 없음(2026-09-13).
- 선불: 장부 **이름·전화번호 행의 마지막 칸(기재사항2)** 빨강 표기(그 행이 없는 화물은 주소행), ERP 코드 반영(2026-09-13).
- 착불은 업체 규칙에 따라 생략 가능(루임트).
- 배송이 택배/화물일 때 포장행 적용.
- 경영박사 택배/화물 품목행 수량 1, `**` 줄은 0(2026-09-13, 전 업체).
- 경영박사 발신 품목코드·품명 = `└ 발 신:`(2026-09-13).
- 루임트: 주소 끝 글자=받는사람. 기재사항에만 `더커튼`→`더`, 주소/수령인은 `더커튼` 그대로(2026-09-13). 선불은 빨간색만.
- 대일 외 발주에 `MIX` 단어가 있으면 MIX 처리.

## 공통 추가 (2026-09-13)
- `심플` = `셔터`.
- 표 형식 발주서는 JO의 좌/우·수량·비고 읽기 규칙을 모든 표 양식에 적용.
- 같은 주문에서 기재사항이 위아래로 같으면 세로 병합(기재사항2가 비면 1·2를 함께), 좌우(1·2)가 같으면 가로 병합. 사전점검·장부·장부→사전점검 모두 동일.
- 사전점검 마지막 행에 총 창수(블라인드·홀딩·롤콤비).
- 연창: 장부 특이 `#`과 같은 창은 경영박사 적요 맨 앞에 `#`.
- 경영박사 적요 `가로*세로/1EA` 다음은 `/` 없이 한 칸 띄움.

## 공통 추가 (2026-09-14)
- 노피스 수량은 `set` 단위(`3EA` → `3set`).
- 기재사항에 피스가 있으면 장부·경영박사 모두 `피스/이름` 순서.
- 석고 부속 종류: 석고앙카, 석고날개(`석고칼블럭-날개` = 석고날개). `석고`만 적히면 석고앙카.
- 장부 세로 반복표시 `"`는 왼쪽+아래쪽 맞춤.
- 경영박사 추가부속 적요 = `수량/이름`(예: `10EA/최군식`), 포장비용 적요 = `이름`. 이름은 받는사람(보노 계열은 지점/받는사람, JL은 고객명). 배송 정보 없는 자기 배송은 이름 없음.
- 경영박사 택배 주소: 번지 뒤 쉼표 없이 상세주소를 새 `**` 줄로(`근흥로 687-1` / `서울한약방`). 장부 주소행은 쉼표 유지.
- 작업지시서에는 주소·이름/전화번호·발신·포장비용을 넣지 않는다(전달사항·부속은 유지).
- 롤스크린 손잡이길이는 5단위 내림(127 → 125).

## 보노(이끌림) / 미래가공
- 미래가공은 보노와 동일 발주/기재/포장 규칙.
- 단 거래처명·관리코드·ERP 상호는 각 업체 유지.
- 받는사람 ≠ 보노 → 이름/상호를 기재1.
- 받는사람이 보노 → 지점 표기(예: 안산초지).
- 기재2 = 오더명/시공위치. 예: `부천67327013/거실1-1`.
- ERP 적요 순서는 손 → 지점 → 방 → 고객정보(오더명). 예: `손120/박달/거실1-1/부천67327013`. 장부는 위 기재1/2 그대로(2026-09-13).
- ERP 지점명은 도시명을 뺀 현장명: `안양박달`→`박달`, `남양주연평`→`연평`. 장부 주소행은 지점명 그대로.
- ERP 화물행 `지점 - 받는사람`, 다음 `**` 줄에 전화번호(`/` 없음). 장부 화물 주소도 전화번호 앞 `/` 없음(2026-09-13).
- 발주서 작동방식필증 칸 내용은 장부 특이사항에 적는다(2026-09-13).
- 롤·콤비 안산)보노/미래가공도 같은 규칙(창당 포장비용 포함)(2026-09-13).
- 포장비는 창당 `포장비용(B/R/C/S/HC)` 코드 체계 사용.
