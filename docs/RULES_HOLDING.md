홀딩도어는 별도 정상 제품군이며, 아래 7개 업체를 지원 대상으로 본다.

- 한길 (K)

중요:
이 업체들은 이미 홀딩도어 대상으로 등록하고 테스트까지 진행했던 업체들이다.
현재 코드에서 일부 규칙이 보이지 않더라도 "규칙이 없는 업체"로 판단하지 말고,
과거 구현이 누락되었거나 복구가 덜 된 상태로 판단해야 한다.

이 7개 업체 외의 홀딩도어 업체를 임의로 추가하지 않는다.

## 홀딩도어 공통 규칙

### 1. 홀딩도어 제품 인식
다음 표현은 홀딩도어 본품으로 인식한다.
- H
- 홀딩
- 홀딩도어
- 자바라

홀딩도어는 블라인드와 별개의 제품군으로 처리한다.

### 2. 작동방식
다음과 같은 작동방식을 지원한다.
- 편
- 양
- 양개
- 양자석
- 1/2, 1/3, 1/4, ... 1/10
- 복합 표기

`양개`는 내부적으로 `양`으로 정규화할 수 있지만, 원 발주의 의미가 사라지면 안 된다.
분수형 표기는 일반 수량으로 변환하지 않는다.

### 3. 홀딩도어 청구면적
홀딩도어 본품의 청구면적은 다음과 같이 계산한다.

```
청구면적 = max( 가로(m) × max(세로(m), 1.5), 2.5㎡ )
```

- 세로 최소 계산값 = 1.5m
- 한 창 최소 청구면적 = 2.5㎡

이 값은 경영박사의 수량/금액 계산 기준으로 사용한다.

### 4. 세로 치수 확인 규칙
홀딩도어 본품:
- 세로 270cm 이상 → 제작 확인 필요
- 세로 300cm 이상 → 사전점검 / 장부 / 작업지시서에서 세로 숫자만 파란색

270cm 이상 확인과 300cm 이상 파란색 표시는 서로 다른 규칙이다.

### 5. 자석바
자석바는 기본 1개 무료다.

```
추가 청구수량 = 실제 자석바 개수 - 1
```

- 자석바 1개 → 추가 청구 없음
- 자석바 2개 → 추가 1개
- 자석바 3개 → 추가 2개

추가 자석바는 경영박사에서 `H추가비용(+자석바1)` 품목으로 청구한다.

### 6. +상하로라
`+상하로라`는 발주서에 실제로 적혀 있을 때만 적용한다. 자동으로 모든 홀딩도어에 추가하면 안 된다.

수량은 가로 길이(m)를 기준으로 하며, 가로 1m 미만 → 수량 1을 최소값으로 사용한다.

### 7. 별도 부속
다음 부속은 홀딩도어 본품과 합치지 않고 별도 행으로 처리한다.
- 레일연결부속
- 라운드부속
- 추가 자석바
- +상하로라

레일연결부속 / 라운드부속에 색상 표기가 없으면 기본 색상은 `화이트`로 처리한다.

### 8. 기존 장부 변환
사람이 직접 작성한 .xls / .xlsx 장부에 `H` 품목이 있는 경우에도 홀딩도어 제품군으로 정상 인식해야 한다.

즉 홀딩도어 규칙은 AI 발주서 처리에만 존재하면 안 되고,
기존 장부 → 작업지시서 → 경영박사 ERP 변환 경로에도 동일하게 적용되어야 한다.

## 업체별 규칙

### 1. 미더스 (K)
- 화면/장부 표시: `미더스 (K)`
- 홀딩도어 공통 규칙 전체 적용: H 본품, 작동방식, 청구면적, 자석바, +상하로라, 레일연결부속/라운드부속, 세로 270cm 이상 제작 확인, 세로 300cm 이상 숫자 파란색
- 포장비: 홀딩도어 청구면적 × 1,000원

별도 예외가 없다고 해서 규칙이 없는 업체가 아니라, 홀딩도어 공통 규칙을 그대로 사용하는 업체다.

### 2. 휴안 (K)
- 화면/장부 표시: `휴안 (K)`
- 홀딩도어 공통 규칙 전체 적용.
- 포장비: 홀딩도어 청구면적 × 1,000원

기재사항/적요 처리:
홀딩도어 ERP 적요에 사용할 이름/현장 정보는 가능한 경우 다음 우선순위로 확인한다.
1. 창의 기재사항
2. 배송 수령인
3. 고객명

경영박사 홀딩 적요에서는 불필요한 공백을 제거한다.
예: `제이원 송길수 부장님` → `제이원송길수부장님`

휴안 홀딩은 단순히 배송 수령인만 사용하는 구조로 만들지 말고, 기재사항/현장 정보를 우선 확인해야 한다.

### 3. 대일
- 화면/장부 표시: `대일` (다른 홀딩 업체와 달리 `(K)`를 붙이지 않는다)
- 홀딩도어 공통 규칙 전체 적용.

대일의 핵심 예외는 `수령인 기준 그룹 처리`다.
같은 수령인의 홀딩도어 본품을 하나의 묶음으로 보고, 수령인이 바뀌는 시점에 해당 수령인의 포장비를 마감한다.

```
수령인 A
H
H
포장비용(H)

수령인 B
H
H
H
포장비용(H)
```

- 대일 홀딩도어 포장비: 홀딩도어 청구면적 × 550원 (대일만 1,000원이 아니라 550원)
- 포장행 품명: `포장비용(H)`

중요: 대일 홀딩도어는 이미 수령인 단위 처리와 ERP 결과 비교 테스트를 진행했던 기능이므로,
현재 코드에서 이 로직이 없으면 신규 규칙으로 보지 말고 누락된 기능으로 판단한다.

### 4. 구미)경남 (K)
- 화면/장부 표시: `구미)경남 (K)`
- 홀딩도어 공통 규칙 전체 적용.
- 포장비: 홀딩도어 청구면적 × 1,000원

추가적인 별도 예외가 없는 경우에도 H 본품 / 작동방식 / 자석바 / 상하로라 / 부속 / 치수 검증은 모두 적용한다.

### 5. 두창 (K)
- 화면/장부 표시: `두창 (K)`
- 홀딩도어 공통 규칙 전체 적용.
- 포장비: 홀딩도어 청구면적 × 1,000원

기존 FitOrder 내부에서는 두창이 `DU` 코드로 관리되었던 부분이 있을 수 있으므로,
- 화면 표시명 = 두창 (K)
- 내부 업체 코드 = 기존 DU/두창 식별자

를 구분해서 유지한다. 리팩터링 과정에서 내부 업체 코드를 화면 표시명으로 단순 치환해서 기존 parser/output 연결을 깨뜨리지 않는다.

### 6. 창문애 (K)
- 화면/장부 표시: `창문애 (K)`
- 홀딩도어 공통 규칙 전체 적용.
- 포장비: 홀딩도어 청구면적 × 1,000원

본품과 부속은 별도 품목으로 관리한다. H 본품 / 레일연결부속 / 라운드부속 / 추가 자석바 / +상하로라가 서로 수량/금액 계산에 섞이지 않도록 한다.

### 7. 한길 (K)
- 화면/장부 표시: `한길 (K)`
- 홀딩도어 공통 규칙 전체 적용.
- 포장비: 홀딩도어 청구면적 × 1,000원

자석바 / 상하로라 / 레일연결 / 라운드부속 / 치수 검증 등 홀딩도어 공통 규칙을 동일하게 적용한다.
