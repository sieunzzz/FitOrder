# 마스터 데이터

`fitorder_master.xlsx` 를 이 폴더에 두어야 프로그램이 동작합니다.
실제 거래처 단가가 포함되어 저장소에는 올리지 않았습니다.

## 필요한 시트 (7개)

### 거래처

| 열 | 예시 |
| --- | --- |
| 상호 | DU |
| 거래처관리코드 | 대구광역시 |
| 단가등급 | 11.출고I가 |
| 단가컬럼 | 출고I가 |
| 배송방식 | 오전배달 |
| 내부표시 | (K) |
| 발주형태 | 카톡사진 |
| 비고 | |

### 품목

| 열 | 예시 |
| --- | --- |
| 품명 | B200(IV)-L18/원코드 |
| 대분류 | 블라인드-L18 |
| 규격 | 0.18mm/원코드 |
| 출고A가 · 출고H가 · 출고I가 · 출고L가 | 23000 |
| 비고2 | 상하:아이보리/실:아이보리 |

`비고2` 의 `실:` 값을 손잡이실 색상으로 사용합니다 (DI 장부 정렬).

### 손잡이실색상

| 열 | 예시 |
| --- | --- |
| 손잡이실 색상 | 아이보리 |
| 슬랫 색상 번호 | 200, 260, 270, 240FP |

### 예외품목

장부에서 제외할 품목 목록. 수리 · 롤스크린 · 홀딩도어 · BMIX · 부속/레일 추가.

### 계산규칙

| 열 | 내용 |
| --- | --- |
| 항목 | 헤베(수량) |
| 규칙 | 가로(m) × 세로(m), 소수 둘째 자리 반올림 |
| 예시 | 1.25 × 1.90 = 2.375 → 2.38 |

참조용입니다. 실제 계산은 `rules.py` 에 구현되어 있습니다.

### 손잡이길이

| 열 | 예시 |
| --- | --- |
| 종류 | 원코드 |
| 세로 조건(cm) | 210 이상 |
| 기본 손잡이 길이 | 손150 |

### 최소사이즈

| 열 | 예시 |
| --- | --- |
| 종류 | 원코드 |
| 최소 가로(cm) | 36 |

## 코드에서 읽는 방식

```python
from rules import Master
M = Master("data/master/fitorder_master.xlsx")

M.find_item("200", "원코드", "L자", "DU")
# {'품명': 'B200(IV)-L18/원코드', '규격': '0.18mm/원코드',
#  '단가': 23000, '단가등급': '출고I가', ...}
```

`품목` 시트만 필수로 파싱하고, 나머지는 코드 상수와 참조용으로 씁니다.
