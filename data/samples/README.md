# 발주서 샘플

정확도 측정용 발주서와 정답 장부를 이 폴더에 둡니다.
실제 고객 정보가 포함되어 저장소에는 올리지 않았습니다.

## 구조

거래처별 폴더 안에 발주서와 정답 장부를 같은 이름으로 둡니다.

```
data/samples/
├─ DU/
│   ├─ DU_01.png        발주서 (카톡 캡처 또는 사진)
│   ├─ DU_01.xlsx       정답 장부 — '장부' 시트
│   ├─ DU_02.png
│   └─ DU_02.xlsx
├─ JO/  JL/  RT/  M/
├─ 휴안/                 엑셀 발주서
└─ DI/
```

확장자만 다르면 코드가 짝을 자동으로 찾습니다.

```python
truth = png_path.with_suffix(".xlsx")
```

## 정답 장부 형식

실제 장부와 동일한 열 구성으로 3행부터 기록합니다.
병합 · `"` 표기 · `#` · `☆` 를 원본 그대로 남겨야 서식 검증이 됩니다.

| A | B 상호 | C 색상 | D 가로 | E | F 세로 | G 수량 | H 모형1 | I 모형2 | J·K 기재사항 | L 출고일 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| | DU (K) | B 원코드 102 | 151.5 | X | 125 | | 좌 | 손120 | ○○아파트112-604/주방 | 화 |

## 측정

```bash
cd src
python evaluate.py ../data/samples          # 전체
python evaluate.py ../data/samples DU       # 거래처 하나
```

결과는 `src/_cache/` 에 저장되어 재실행 시 재사용됩니다.
프롬프트를 수정했으면 캐시를 지우고 다시 돌립니다.

```bash
rm -rf _cache
```

## 채점 방식

핵심 필드(색상 · 가로 · 세로 · 수량 · 모형1 · 모형2)는 정확히 일치해야 하고,
기재사항은 정답 내용이 추출 결과에 포함되면 통과로 봅니다.
담당자가 임의로 줄여 쓰는 표기가 있어 완전 일치를 요구하지 않습니다.
